## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
- 다양한 취미와 관심사를 기반으로 사용자 간 콘텐츠를 공유하고 소통할 수 있는 취미 기반 SNS 플랫폼(ITDA) 구축.
- 좋아요·댓글·스크랩·팔로우·구독 등의 기능을 통해 지속적으로 상호작용할 수 있는 소셜 환경 제공
- 특정 사용자를 구독한 회원에게만 구독자 전용 게시글을 제공하여 창작자와 구독자 간의 지속적인 관계 형성 및 차별화된 콘텐츠 제공.
- 사용자가 자신의 SNS 화면에 적용할 수 있는 개인화 테마를 구매·적용할 수 있도록 하여 콘텐츠뿐만 아니라 사용자별 UI 환경까지 개인화할 수 있는 기능 제공.
- Spring Boot 기반의 REST API 백엔드와 React 기반의 클라이언트 애플리케이션 간 비동기 데이터 통신 체계 확립.
- 전자결제 대행(PG) API 연동을 통해 일반 사용자와 유료 창작자 간의 구독 결제 및 멤버십 비즈니스 모델(BM) 적용.

### 1.1.2 서비스 주요 특징
- JWT(JSON Web Token) 기반 무상태 인증 및 RTR(Refresh Token Rotation) 재발급 보안 체계 적용.
- 텍스트와 이미지를 활용한 SNS 게시글 작성 및 공유.
- 댓글, 좋아요 토글, 스크랩 보관함을 통한 사용자 간 양방향 소셜 인터랙션 제공.
- 월간 유료 구독 및 전용 게시글 접근 권한 제어.
- 결제를 통한 디지털 테마 구매 및 사용자 인터페이스 변경
- AWS 인프라(EC2, S3) 기반의 고성능 분리 배포 환경 구축.

## 1.2 주요 기능 요구사항

### 1.2.1 회원 및 인증 관리 기능-회원가입(이메일, 비밀번호, 닉네임, 프로필 이미지).
- 회원가입 (이메일, 비밀번호, 닉네임, 프로필 이미지)
- JWT 기반 로그인 및 토큰 발급(Access Token, Refresh Token).
- 만료 토큰 자동 갱신(RTR 전략 적용).
- OAuth 2.0 기반 소셜 로그인 (카카오, Google 등)
- 내 프로필 조회 및 마이페이지 정보 수정.

###  1.2.2 취미 SNS 게시글 관리 기능-피드 게시글 목록 조회(페이징, 키워드 검색).
- 신규 게시글 작성(본문 작성, AWS S3 이미지 업로드).
- 게시글 상세 조회, 수정, 삭제(본인 작성 피드 제어).
- 구독 전용 유료 게시글 표시 및 접근 권한 분기.
- 사용자별 테마 구매 및 적용 테마 관리

### 1.2.3 소셜 상호작용 기능-피드 댓글 작성, 목록 조회, 삭제.
- 게시글 좋아요(Like) 토글 및 실시간 좋아요 수 증감.
- 관심 피드 스크랩 저장, 취소 및 목록 조회.
- 게시글 상세에서만 댓글 작성, 수정 및 삭제 기능
- 구독 게시글, 댓글 작성시 알림 기능
- 게시글 신고 기능

### 1.2.4 결제 및 구독 관리 기능-브라우저 결제창 SDK 연동을 통한 결제창 호출 및 단건 결제.
- 서버 사이드 결제 사전/사후 검증 API를 통한 결제 금액 위변조 방지.
- 월간 정기 구독을 위한 빌링키(Billing Key) 발급 및 저장.
- 정기 결제 스케줄러(Spring Batch / Scheduled) 기반 월 자동 결제 실행.
- 결제 취소, 환불 및 결제 웹훅(Webhook) 비동기 수신 처리.

### 1.2.5 테마 및 구독결제 관리 기능
- 테마 목록 및 상세 정보 조회(테마 미리보기, 가격, 설명).
- PG 결제 SDK를 통한 테마 단건 결제.
- 결제 사전 등록 및 서버 사이드 결제 검증을 통한 결제 금액 위변조 방지.
- 결제 웹훅(Webhook)을 통한 결제 상태 확인 및 동기화.
- 구매 테마 조회 및 사용자별 적용 테마 관리.
- 로그인 시 저장된 사용자 테마를 사이트 전체 UI에 적용.
- 새로고침 및 재로그인 이후에도 사용자 테마 설정 유지.
- 테마는 사용자별로 독립적으로 적용되어 본인 화면에서만 변경된 디자인 제공.
- 특정 사용자를 구독시 그 사용자의 구독자 전용 게시글을 열람 가능
- 구독은 한 달 단위로 갱신 가능
- 구독 페이지에서 구독 남은 일수 확인 및 구독 해제 가능

#### 1.2.6 관리자 관리 기능
관리자 전용 로그인 및 권한 관리
- 관리자 계정 기반 로그인 및 관리자 페이지 접근 권한 관리
- 일반 사용자와 관리자의 접근 권한 분리

결제 관리
- 전체 결제 내역 조회
- 결제 사용자, 결제 상품, 결제 금액, 결제 일시 및 결제 상태 확인
- 결제 성공·실패·취소 등의 상태별 조회 및 검색
- 결제 상세 내역 확인

환불 관리
- 환불 요청 및 환불 처리 내역 조회
- 환불 대상 결제 정보 및 환불 금액 확인
- 환불 처리 상태 관리
- 환불 완료 및 처리 결과 확인

구독 관리
- 사용자별 구독 내역 조회
- 구독 대상 창작자(구독을 받는 대상), 구독자, 구독 시작일 및 종료일 확인
- 활성·만료·해지 등 구독 상태 조회
- 구독 결제 및 갱신 내역 확인

회원 관리
- 전체 회원 목록 조회 및 검색
- 이메일, 닉네임 등을 기준으로 회원 검색
- 회원 상세 정보 및 가입일 확인
- 회원의 게시글, 결제 및 구독 내역 조회

게시글 및 신고 관리
- 전체 게시글 조회 및 검색
- 신고 접수 게시글 및 댓글 조회(후순위)
- 신고 사유 및 신고 대상 사용자 확인(후순위)
- 신고 처리 상태 관리(후순위)
- 운영 정책에 위배되는 게시글 및 댓글 삭제 처리(후순위)
- 신고 처리 결과 확인(후순위)

테마 관리
- 서비스에서 판매할 테마 등록
- 테마명, 설명, 가격, 미리보기 이미지 등의 정보 관리
- 테마 수정 및 판매 상태 관리
- 판매 중지 및 삭제 처리
- 등록된 테마 목록 및 판매 현황 조회
